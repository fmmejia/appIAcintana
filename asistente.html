    Configurar Conexión de Inteligencia Artificial

    Tus claves se almacenan de forma local en tu navegador y nunca salen de tu dispositivo. El asistente utilizará estas claves para analizar los datos académicos activos.

    ¿Cómo obtener tu Clave API?

    Google ofrece un plan de uso gratuito excelente para desarrolladores y docentes. Para obtener tu clave:

    1. Ve al portal oficial de desarrolladores en Google AI Studio.
    2. Inicia sesión con tu cuenta institucional o personal de Google.
    3. Haz clic en el botón azul "Get API Key" (Obtener clave API) en la esquina superior izquierda.
    4. Selecciona "Create API Key" y cópiala.
    5. Pega la clave en el campo de texto superior y haz clic en Guardar.

    Requiere una cuenta de desarrollador en OpenAI Platform con saldo prepago cargado (no las cuentas de suscripción de ChatGPT Plus). Para obtener tu clave:

    1. Inicia sesión en OpenAI API Keys.
    2. Haz clic en el botón "Create new secret key" (Crear nueva clave secreta).
    3. Asígnale un nombre descriptivo y haz clic en crear.
    4. Copia la clave inmediatamente (empieza con sk-), ya que no se volverá a mostrar.
    5. Pégala en el campo de arriba y guarda tu configuración.

    ⚠️ Nota de Compatibilidad: Claude no admite llamadas directas desde navegadores web debido a restricciones CORS de Anthropic. Se recomienda usar Google Gemini o OpenAI para esta versión web pura.

    Si deseas probar con Claude mediante un servidor proxy:

    1. Inicia sesión en Anthropic Console.
    2. Dirígete a la sección "API Keys" en la barra de navegación del portal.
    3. Haz clic en "Create Key" para generar tu clave.
    4. Copia el token generado (empieza con sk-ant-) y colócalo en el campo de entrada superior.
